# Sample notes vault

This folder is a tiny, self-contained Markdown vault used by the README quick
start and the test suite. Point ObsidianRAG at any folder of `.md` files the
same way.

- [chunking](chunking.md) explains how notes are split into passages.
- [embeddings](embeddings.md) describes how passages become vectors.
- [cli](cli.md) documents the command-line workflow.
